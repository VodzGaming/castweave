# CastWeave 0.5.1

- Keeps Chat and Streams as separate OBS docks.
- Moves shared settings into a modeless window available from the Chat gear and **Tools > CastWeave Settings**.
- Adds a guided Windows installer with a license page, progress, uninstall support and optional OBS launch.
- Retargets verified updates to `zerithvt-Coder/castweave` after the repository transfer.
- Removes unused OBS template sources and derives the displayed version from `buildspec.json`.
- Adds updater and preview checks to the Windows build workflow.

YouTube and Kick integrations remain visual placeholders in this release.
